## Capture on Windows 10

1. Run the required file with F5 in SQL Developer.
2. Enlarge Script Output so the text is readable. For the wide B5 report,
   widen the panel or use the query result grid after running the SELECT.
3. Press **Windows + Shift + S**, select the useful area, and save the
   screenshot from Snipping Tool as a PNG.
4. Save it in this folder using the exact required filename.
5. For A3, keep both the error and corrected output visible. If the panel
   is small, resize it before capturing.
6. Open the PNG and confirm the text is legible. Include enough of the
   application or query to make the screenshot understandable.

The `test_functions.sql` output can be saved as an additional
`B1_B4_tests_output.png` if useful. The six images above are the named
requirements in the assignment PDF.

Do not replace the required execution evidence with the expected-results
table. Do not include credentials in screenshots.
